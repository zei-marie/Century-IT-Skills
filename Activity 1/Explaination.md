# Activity 1: Presentation Design Principles

## Project Overview

For this activity, I created a promotional poster design for "Arrupe Hall Booth 7" featuring a free coffee booth event.

The goal of this activity was to apply presentation design principles to create a visually appealing and informative digital output.

## Design Principles Applied

### Visual Hierarchy

I arranged elements according to importance. The event title and "Free Coffee" message were emphasized to immediately capture the audience's attention.

### Contrast

Dark backgrounds and lighter text colors were used to improve readability and make important information stand out.

### Alignment

The elements were positioned properly to create an organized and balanced layout.

### Balance

Visual elements such as the coffee cup, text, and event details were distributed to create a pleasing composition.

### Consistency

Colors, fonts, and design elements were kept consistent to maintain a unified theme.

### Simplicity

Only important information was included to avoid overwhelming the audience.

## Reflection

Through this activity, I learned that effective design is not only about making something visually attractive but also about communicating information clearly.

As a nursing student, these skills can help me create better educational materials, presentations, and health-related information using digital tools.
